# 🌍 Tourism Website

A simple and responsive **Tourism Website** developed using **HTML5 and CSS3**. The website showcases tourist destinations with an attractive and user-friendly design.

## 🛠️ Technologies
- HTML5
- CSS3

## ✨ Features
- Responsive design
- Tourist destination sections
- Attractive images and layouts
- Simple navigation
- User-friendly interface

## 🚀 How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. For development, use VS Code with Live Server.
