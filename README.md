# 🌍 ExploreTheWorld – Tourism Website

ExploreTheWorld is a responsive tourism website designed to showcase popular travel destinations and inspire users to explore the world. The website features a clean, attractive interface with destination information, images, and easy navigation.

### 🛠️ Tech Stack
- HTML5
- CSS3

### ✨ Features
- Responsive and user-friendly design
- Attractive destination sections
- Clean navigation
- Image-based travel presentation
- Simple and lightweight frontend

### 🚀 Purpose
This project was developed to practice frontend web development and create a visually appealing tourism website using HTML and CSS.
